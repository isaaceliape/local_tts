  <action>
    Create the TTSModel class that will be loaded once at application startup:

    1. In backend/services/tts.py:
       - Set PYTORCH_ENABLE_MPS_FALLBACK=1 BEFORE any imports (critical for M1)
       - Import torch, kokoro.KPipeline, and config
       - Create TTSModel class with:
         ```python
         class TTSModel:
             def __init__(self):
                 self.device = self._get_device()
                 self.pipeline = KPipeline(lang_code=config.LANG_CODE)
                 self.voices = config.VOICE_CONFIGS  # Dict of voice_id -> display_name
                 self._warmup()
             
             def _get_device(self) -> torch.device:
                 if torch.backends.mps.is_available():
                     return torch.device("mps")
                 return torch.device("cpu")
             
             def _warmup(self):
                 # Run dummy inference to warm up model
                 list(self.pipeline("Hello", voice=config.DEFAULT_VOICE))
             
             def get_voices(self) -> list[VoiceInfo]:
                 return [VoiceInfo(id=k, name=v) for k, v in self.voices.items()]
             
             def generate(self, text: str, voice: str = None, speed: float = 1.0):
                 voice = voice or config.DEFAULT_VOICE
                 if voice not in self.voices:
                     voice = config.DEFAULT_VOICE
                 
                 with torch.no_grad():
                     generator = self.pipeline(text, voice=voice, speed=speed)
                     results = list(generator)
                     if results:
                         return results[0].audio  # numpy array
                 return None
         ```

    2. In backend/models/schemas.py:
       - TTSRequest: text (str), voice (str, default="af_heart")
       - TTSResponse: audio_url (str) or audio_data (bytes) - defer to Plan 02
       - VoiceInfo: id (str), name (str)
       - VoicesResponse: voices (list[VoiceInfo])

    3. Add proper type hints and docstrings
    4. Test TTSModel instantiation in isolation (verify model loads, MPS is used)

    Key decisions from research:
    - Use KPipeline with lang_code='a' for American English
    - Voices are downloaded on-demand from HuggingFace Hub on first use
    - Warmup is critical to avoid slow first inference in production
    - torch.no_grad() is required for inference memory efficiency
